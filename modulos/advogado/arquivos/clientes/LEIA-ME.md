# CLIENTES (sigiloso)

Esta pasta existe para manter o dado do cliente **dentro da sede dela** e longe do resto. O que ela disse no bloco A sobre sigilo vale acima
de tudo o que está aqui.

## Regras
1. Uma pasta por cliente: `sede/clientes/<iniciais-ou-código>/` (ex.: `sede/clientes/MAS-2026-01/`). Nome completo só dentro da `FICHA.md`.
2. Dentro: `FICHA.md` (copiar de `_MODELO/FICHA.md`), `HISTORICO.md`, `documentos/`, `pecas/`, `comunicacoes/`.
3. Nada desta pasta vai para `ESTADO.md`, `DIARIO.md`, `LICOES.md`, `PERFIL.md`, post, site, mensagem a terceiros ou link compartilhado.
4. Se a sede estiver no GitHub, o repositório é **privado**; mesmo assim, se ela preferir, esta pasta pode ficar só no computador: basta
   movê-la para `sede/clientes/_privado/` (o `.gitignore` já deixa `_privado/` de fora). Ela decide.
5. Dado sensível (saúde, crime, menores, vida sexual, religião, biometria): só o necessário ao caso. Menor de idade: só iniciais.
6. Se ela usa termo de uso de IA com os clientes (bloco A), o Estrategista confere na `FICHA.md` antes de trabalhar no caso e, se faltar,
   oferece o modelo `sede/modelos/termo-uso-ia.md` uma vez. Se ela não usa, não insiste.
7. O que o Estrategista lê passa pelos servidores do motor (Anthropic ou OpenAI). Por isso: treino com as conversas desligado na conta e o
   mínimo de dado pessoal na conversa.
8. Encerrou o caso? Ela decide o que guardar e por quanto tempo. O Estrategista não apaga nada sozinho.

Este modelo vem **sem nenhum dado real**.
