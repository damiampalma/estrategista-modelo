# MODELOS

Aqui ficam os modelos **dela**: peças, contratos, procurações, e-mails, mensagens, relatórios. O Estrategista escreve no estilo que está aqui.

- Um arquivo por modelo, com nome claro: `peca-contestacao-civel.docx`, `email-atualizacao-cliente.md`, `contrato-honorarios.docx`.
- Modelo sem dado de cliente: nomes e números viram campos, como `[CLIENTE]`, `[PROCESSO]`, `[VALOR]`.
- Quando ela disser "esse é o meu padrão", o Estrategista anota aqui e em `sede/LICOES.md` qual arquivo usar para cada tipo.

| Tipo | Arquivo padrão | Observação |
|---|---|---|
| Termo de uso de IA (cliente) | `termo-uso-ia.md` | Rascunho pronto para ela revisar e adotar, se quiser |
