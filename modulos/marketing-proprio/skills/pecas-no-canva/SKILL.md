# Peças no Canva

Objetivo: tirar dela o trabalho de conferir, baixar e agendar à mão. Ela abre o link, confere e agenda dentro do próprio Canva.

## Entradas
- `marketing/semanas/AAAA-MM-DD.md` (posts com status "aprovado"), templates listados em `sede/FERRAMENTAS.md`.

## Passos
1. Canva conectado? Se não: ofereça conectar (`conectar-ferramentas`) **ou** entregue agora os textos de cada post (título, apoio, legenda) prontos
   para ela colar no template. Não trave a semana por causa do conector.
2. Para cada post aprovado: faça uma **cópia** do template certo e troque os textos (título, apoio, chamada). Nunca edite o template original.
   Se o texto não couber, encurte e avise; não diminua a fonte abaixo do que o template usa.
3. Nome claro na cópia: `AAAA-MM-DD · tema curto`.
4. Grave o link de cada peça em `marketing/semanas/AAAA-MM-DD.md` e mude o status para "no Canva".
5. Mande a lista de links com a legenda de cada um logo abaixo (pronta para copiar) e o passo a passo, uma vez:
   **No Canva:** abra a peça → Compartilhar → "Agendar" (ou Planejador de Conteúdo) → escolha o Instagram → cole a legenda → data e hora.
   (Precisa do Instagram profissional ligado à Página do Facebook. Nome do menu pode variar.)
6. Quando ela disser que agendou, status "agendado". Salve.

## Limites
- Você não agenda nem publica: ela faz.
- Foto de cliente, de obra ou de imóvel de terceiro só com autorização dela.
